🎙 Speech Processorsrc/speech_processor.py
  • _load_audio_file(path)module fnMulti-backend waterfall: torchaudio.load (if <2.9) → soundfile.read → scipy.io.wavfile → torchcodec. Returns (ndarray, sample_rate).
  • _resample_numpy(wav_np, src_sr, dst_sr)module fnResamples ndarray via torchaudio.transforms.Resample (preferred) or numpy linear interp fallback. Returns float32 ndarray.
  • TimingBreakdowndataclassPer-stage timing: model_load_s, audio_load_s, tokenization_s, device_transfer_s, generate_s, decode_s, total_s. .report(audio_duration_s) produces RTFx breakdown.
  • SpeechResultdataclassOutput container: text, task, source_language, target_language, audio_duration_s, processing_time_s, device_used, model_name, segments, timing. Properties: realtime_factor, timing_report().
  • PerfConfigdataclassKnobs: int8_quantize, compile, use_cache, max_new_tokens_short, short_clip_threshold_s, num_beams, profile.
  • GraniteSpeechProcessor.__init__classConstructor: model_name, device, torch_dtype, cache_dir, perf. Lazy-loads model on first transcribe/translate call.
  • .devicepropertyResolves "auto" to cuda/mps/cpu based on torch availability.
  • .is_loaded()methodReturns True when model weights are loaded in memory.
  • .load()methodExplicitly loads model; no-op if already loaded.
  • .unload()methodReleases model references and calls gc.collect(); no-op when not loaded.
  • .transcribe(waveform_or_path, language, max_new_tokens)methodPublic transcription entry point. Accepts file path or numpy array. Returns SpeechResult.
  • .translate(waveform_or_path, source, target, max_new_tokens)methodPublic translation entry point. Resolves BCP-47 codes via LANGUAGE_NAMES to full names before building prompt.
  • ._load_model()privateLoads AutoProcessor + AutoModelForSpeechSeq2Seq from HuggingFace; applies INT-8 quantisation or torch.compile() per PerfConfig.
  • ._load_audio(path_or_array)privateDispatches to _load_audio_file() or passes through ndarray; resamples to TARGET_SAMPLE_RATE.
  • ._split_segments(waveform)privateSplits Tensor into ≤MAX_SEGMENT_SECONDS (119 s) frame-aligned chunks.
  • ._run(waveform, prompt, max_new_tokens)privateCore inference loop: adaptive token cap for short clips, per-segment decode, timing instrumentation. Decorated @torch.inference_mode().
  • LANGUAGE_NAMESconstantDict mapping BCP-47 codes to full English names (e.g. "fr" → "French"). Covers en, fr, de, es, pt, ja + it, zh.
  • PROMPT_TEMPLATESconstantDict of prompt strings keyed by task: "transcribe", "translate_to_en", "translate_from_en". All contain <|audio|> placeholder.

  • detect_hardware()module fnConvenience wrapper: HardwareDetector().detect().

🔬 Key Design Decisions & Bug History

Decision / BugDetail
AutoModelForSpeechSeq2SeqGranite Speech 5.0-2B uses AutoModelForSpeechSeq2Seq + AutoProcessor from transformers ≥ 4.52.1. Requires 16 kHz mono audio as input.
torchaudio ≥ 2.9 removed bundled backendsFixed with multi-backend _load_audio_file() waterfall: torchaudio → soundfile → scipy → torchcodec. _TORCHAUDIO_IO_OK guards the first branch.
Translation language name bugModel requires full names ("French") not BCP-47 codes ("fr"). Fixed via LANGUAGE_NAMES dict resolved before prompt formatting. Regression tests added.
bool("false") == TruePython's built-in bool("false") returns True. Fixed with _as_bool() helper in config_manager.py; used for all boolean config fields.
Full Pipeline LLM skip bugtranscript.startswith("") is always True. Fixed to startswith("❌") to correctly skip LLM on transcription errors.
Browser microphone requires HTTPSFixed by generating self-signed TLS cert (certs/cert.pem + key.pem) via openssl in setup.sh. Passed to Gradio via ssl_certfile, ssl_keyfile, ssl_verify=False.
Gradio ssl_verify=False requirementGradio 6.x makes an internal httpx health-check after binding HTTPS. Without ssl_verify=False it crashes with CERTIFICATE_VERIFY_FAILED on startup.
Gradio "true" filename buggr.Audio input widgets with default buttons=["download","share"] triggered a save-dialog showing "true" as filename under HTTPS. Fixed by setting buttons=["share"] on all Audio inputs.
IBM Vault Radar cert detectionVault Radar flags any X.509 .pem file as medium severity. certs/cert.pem and key.pem are excluded from git via .gitignore and must never be committed. Quickstart documents the git rm --cached recovery procedure.
granite4.2 thinking-model empty contentgranite4.2:latest is a reasoning model that generates a <think>…</think> block. If max_tokens is too low the model exhausts its budget during the think phase and content="" is returned. Fixed by defaulting max_tokens=1024 and adding a fallback to the reasoning field.
device_map= vs .to(device)device_map= requires the accelerate library as a hard dependency. Using .to(device) avoids this dependency; the device string is resolved from HardwareProfile.
